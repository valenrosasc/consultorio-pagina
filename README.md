## 🚀 Cómo subir a Netlify (3 minutos)

### Paso 1: Crear cuenta
1. Ve a [netlify.com](https://netlify.com)
2. Click en "Sign up"
3. Crea cuenta con Google, GitHub o Email

### Paso 2: Subir el sitio
1. Click en "Add new site"
2. Selecciona "Deploy manually"
3. Arrastra TODA la carpeta "Consultorio pagina" a la ventana
4. Espera 30 segundos (sube automáticamente)

### Paso 3: Cambiar el nombre
1. Ve a "Site settings"
2. Click en "Change site name"
3. Escribe: `consultorio-rosas` (o tu preferencia)
4. Tu link será: **https://consultorio-rosas.netlify.app**
